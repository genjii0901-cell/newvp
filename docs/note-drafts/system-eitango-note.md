# システム英単語を、今日から「解ける・印刷できる・続けられる」形へ

## 無料公開部分

システム英単語を進めているのに、

- 覚えたつもりでもテストで出てこない
- 範囲ごとの小テストを用意する時間がない
- 音読・聞き流し・確認テストが別々になって続かない

と感じることはありませんか。

このページでは、**システム英単語を使っている学習者向け**に、Vocab Print Pro の購入者用ページを案内します。単語帳そのものの代わりではなく、手元の単語帳で学ぶための補助ツールです。

[画像: システム英単語用ページの全体画面]

## できること

### 1. 必要な範囲だけ、テスト形式で印刷

番号の範囲を指定し、英語空欄・日本語空欄・スペルテストなどから形式を選べます。授業前の確認、朝学習、週末の復習用に、必要な分だけ作れます。

[画像: 印刷設定画面。開始番号・終了番号・形式が見えるもの]

[画像: 実際に出力したA4テストの例。名前欄・問題欄・解答欄が見えるもの]

### 2. 聞いて、見て、すぐ確認

英語と意味を順に聞き流しながら、画面でも確認できます。速度・間隔・反復回数を自分のペースに合わせ、迷った単語には印を付けて後から見直せます。

[画像: 聞き流し画面。単語、意味、再生速度、苦手マークが見えるもの]

### 3. 「分かる」ではなく「答えられる」を確かめる

単語カードと4択チェックで、思い出す練習ができます。単語学習では、答えを見直すだけでなく、自分で取り出す練習が学習を支えることが知られています。Vocab Print Pro は、印刷・聞き流し・単語チェックを行き来しやすくして、復習のきっかけを減らします。

[画像: 単語カードまたは4択チェック画面。進捗と苦手マークが見えるもの]

## このページが向いている人

- システム英単語を使っている
- 自分の苦手な範囲を短く確認したい
- 家庭学習や授業用に、A4の小テストをすぐ用意したい
- 紙とスマホの両方を使って復習したい
